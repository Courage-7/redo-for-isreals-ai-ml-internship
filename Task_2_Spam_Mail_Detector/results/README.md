# Evaluation Results and Visualizations

This directory contains evaluation outputs generated during training and assessment:

* `class_distribution.png`: Class breakdown between Ham and Spam showing imbalance.
* `message_length_distribution.png`: Character and word count distributions comparing Ham and Spam.
* `top_spam_words.png`: Top distinguishing tokens in spam vs legitimate messages.
* `model_comparison.png`: Comparison of Accuracy, Precision (Spam), Recall (Spam), and F1 across models.
* `confusion_matrix_comparison.png`: Normalized confusion matrices for all evaluated models.
