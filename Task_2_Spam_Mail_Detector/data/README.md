# SMS Spam Collection Dataset

This directory contains the authentic SMS Spam Collection dataset directly downloaded from the **UCI Machine Learning Repository** as specified in the internship guidelines.

- **Source**: UCI Machine Learning Repository
  - Permanent URL: `https://archive.ics.uci.edu/dataset/228/sms+spam+collection`
  - Direct Archive: `https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip`
- **Authors**: Tiago A. Almeida and José María Gómez Hidalgo
- **Files in Directory**:
  - `SMSSpamCollection`: Original raw tab-separated file from UCI.
  - `SMSSpamCollection.csv`: Pre-parsed CSV format with `label` and `message` headers.
  - `uci_readme.txt`: Original authors' readme document detailing dataset collection and statistics.
- **Dataset Composition**:
  - Total records: 5,574 messages
  - Non-spam (ham): 4,827 messages (~86.6%)
  - Spam: 747 messages (~13.4%)
