# SMS Spam Collection Dataset

This directory contains the SMS Spam Collection dataset downloaded from the UCI Machine Learning Repository as specified in the internship guidelines.

* Source: UCI Machine Learning Repository (Dataset ID: 228)
* Permanent URL: https://archive.ics.uci.edu/dataset/228/sms+spam+collection
* Files in Directory:
  1. `SMSSpamCollection`: Original raw tab-separated file from UCI.
  2. `SMSSpamCollection.csv`: Pre-parsed CSV format with label and message headers.
  3. `uci_readme.txt`: Original dataset documentation detailing collection and statistics.
* Dataset Composition:
  * Total records: 5,572 messages
  * Non-spam (ham): 4,825 messages (86.6%)
  * Spam: 747 messages (13.4%)
