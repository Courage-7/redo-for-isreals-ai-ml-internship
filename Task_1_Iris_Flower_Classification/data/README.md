# Iris Dataset

This directory contains the Iris dataset sourced from the UCI Machine Learning Repository as specified in the internship guidelines.

* Primary Source: UCI Machine Learning Repository (Dataset ID: 53)
* Number of Instances: 150 (50 per class)
* Features:
  1. sepal_length (cm)
  2. sepal_width (cm)
  3. petal_length (cm)
  4. petal_width (cm)
* Target Classes:
  1. Setosa (Class 0)
  2. Versicolor (Class 1)
  3. Virginica (Class 2)
