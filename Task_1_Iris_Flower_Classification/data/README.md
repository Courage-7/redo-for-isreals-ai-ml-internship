# Iris Dataset

This directory contains the authentic Iris dataset sourced from the **UCI Machine Learning Repository** as specified in the internship guidelines.

- **Primary Source**: UCI Machine Learning Repository
  - URL: `https://archive.ics.uci.edu/ml/machine-learning-databases/iris/iris.data`
- **Secondary / Built-in Source**: `sklearn.datasets.load_iris()`
- **Number of Instances**: 150 (50 per class)
- **Features**:
  1. `sepal_length` (cm)
  2. `sepal_width` (cm)
  3. `petal_length` (cm)
  4. `petal_width` (cm)
- **Target Classes**:
  - `Setosa` (Class 0)
  - `Versicolor` (Class 1)
  - `Virginica` (Class 2)
