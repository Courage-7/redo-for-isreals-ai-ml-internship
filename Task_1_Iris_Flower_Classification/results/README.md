# Evaluation Results and Plots

This directory stores exported high-resolution visualizations and evaluation reports generated by the project workflow:

* `eda_distributions.png`: Feature histograms and KDE plots across all classes.
* `eda_boxplots.png`: Feature box plots demonstrating class separability.
* `eda_correlation.png`: Feature correlation matrix heatmap.
* `eda_pairplot.png`: Full multi-feature pair plot with class hue.
* `model_comparison.png`: Bar chart comparing Accuracy, Precision, Recall, and F1 across all trained models.
* `confusion_matrix.png`: Normalized and annotated confusion matrix for the champion classifier.
